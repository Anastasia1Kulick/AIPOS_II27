# Цель

Реализовать на языке программирования высокого уровня Java клент-серверное взамодействие, организованной через UDP.

# Задание на выполнение (Сервер)

1. Изучить теоретический материал, функции и классы пакета `java.net` и листинг программы реализации UDP-сервера. Получить индивидуальное задание у преподавателя.

2. Разработать программу работы UDP-эхо-сервера, выполняющую функции согласно варианта задания (см. приложения). В качестве клиента использовать программу `telnet`.

3. Представить отчет, содержащий титульный лист, листинг программы с подробными комментариями основных фрагментов программы.

4. Подготовиться к защите лабораторной работы по теоретическому материалу, функциям, собственным результатам, полученным в ходе выполнения лабораторной.

# Задание на выполнение (Клиент)

1. Изучить теоретический материал, функции и классы пакета `java.net` и листинг программ реализации UDP-клиента.

2. Разработать программу работы UDP-клиента. Выполнить проверку программы с использованием разработанного в предыдущей лабораторной работе TCP-сервера. Продемонстрировать работу системы преподавателю.

3. Представить отчет, содержащий титульный лист, листинг программы с подробными комментариями основных фрагментов программы.

4. Подготовиться к защите лабораторной работы по теоретическому материалу, функциям, собственным результатам, полученным в ходе выполнения лабораторной.
